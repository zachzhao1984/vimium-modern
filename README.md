# Vimium Modern

Vimium Modern is a keyboard-driven browser extension built in the spirit of Vim. Navigate, search, open links, and manage tabs without leaving the keyboard.

## Features

- Vim-style page navigation and link hints
- Omnibar search for URLs, bookmarks, history, tabs, and commands
- Per-site exclusion rules
- Chinese and English interface, with English as the default
- A fast filament animation when jumping between Find matches with n / N

## Install

1. Open chrome://extensions in Chrome or Edge.
2. Turn on Developer mode.
3. Choose Load unpacked and select this repository.

No build step is required.
