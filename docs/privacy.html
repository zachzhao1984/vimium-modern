Privacy Policy

Vimium Modern · Effective 2026-11-11

Vimium Modern is designed to work locally in your browser. It does not create an account, operate a server, or send your browsing data to its developers.

Data the extension uses

To provide keyboard navigation, search completion, link hints, and tab management, Vimium Modern may access the following data on your device:

  • Tabs, tab titles, URLs, and recent tab activity
  • Browser history and bookmarks
  • The page content you are viewing, used for link hints and find-in-page
  • Your extension settings and per-site exclusion rules

This data is processed locally in the browser. Vimium Modern does not transmit browsing history, bookmarks, page content, or a list of your tabs to the developer.

Search suggestions

When you type in the Omnibar, the extension may request autocomplete suggestions from the search engine associated with the current site or the selected search engine. That query is sent directly to the search provider, such as Google, Bing, DuckDuckGo, Wikipedia, or the search URL you configure. Those providers handle the request under their own privacy policies.

Settings and sync

Settings are stored using Chrome’s extension storage. If Chrome Sync is enabled, Chrome may synchronize extension settings through your Google account. Vimium Modern does not separately collect or receive that synchronized data.

No sale, advertising, or analytics

Vimium Modern does not sell data, serve advertising, or include analytics or tracking SDKs. It does not use remote code or load executable code from a remote server.

Permissions

Site access and browser permissions are used only for the extension’s keyboard navigation and search functionality. You can review installed permissions in Chrome and remove the extension at any time.

Contact

For privacy questions or deletion of locally stored extension data, use the project’s GitHub issue tracker. You can remove all extension data by uninstalling Vimium Modern or clearing its extension storage.

Changes

If this policy changes, the updated policy will be published at this URL with a new effective date.
